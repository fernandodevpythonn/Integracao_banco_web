Página de listas

As listas são criadas com as tags ul,ol e dl

ul
Lista não ordenada (sem ordem especifica)
ol
Lista ordenada (Ordem alfabética ou númerico)
dl
lista de definição (utilizada para descrever algo)

Exemplos:

Lista ordenada:

  1. Exemplo 01
  2. Exemplo 02
  3. Exemplo 03
  4. Exemplo 04
  5. Exemplo 05

Lista não ordenada:

  • Item a
  • Item b
  • Item c
  • Item d
  • Item e

Lista de definição:

Carro
Veículo de 4 rodas
Github
Repositório remoto de cógido de um sistema
